# SOP 与自动化：把自己从重复劳动中解放

## 四步法
1. **记录**：连续一周记录自己做的所有任务和耗时。
2. **写 SOP**：把重复出现的任务写成标准作业流程：触发条件、输入、步骤、输出、检查标准。
3. **评分**：对每个任务按“频率 × 单次耗时 × 规则化程度”打分，规则越清晰越适合自动化。
4. **自动化**：从得分最高的任务开始，用工作流工具或 Agent 实现，并保留人工审核点。

## 适合优先自动化的任务
- 线索收集与整理（从网站、表单、平台抓取到表格/CRM）。
- 首轮邮件回复、FAQ 客服（配合 RAG 知识库）。
- 内容改写与多平台分发。
- 发票、报价单、周报生成。
- 数据汇总与看板更新。

## 不适合完全自动化
- 涉及付款、合同承诺、对外重要沟通的最终发送。
- 高度依赖判断和关系的环节（谈判、重要客户维护）。
这些环节用 AI 起草、人来拍板。

## 衡量自动化效果
节省时间（小时/周）、错误率变化、响应速度、单位成本，以及自动化本身的维护成本。若维护成本超过节省的时间，就要简化或放弃。
