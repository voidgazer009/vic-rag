# Incoterms 2020 贸易术语全解

Incoterms® 由国际商会（ICC）制定，现行版本为 Incoterms 2020（2020 年 1 月 1 日生效），共 11 个术语。它只规定买卖双方在**交货地点、风险转移、费用划分、进出口清关**上的责任，不涉及货物所有权转移和付款方式。合同里写法建议：“FOB Ningbo Incoterms® 2020”。

## 两大类
- **适用于任何运输方式（7 个）**：EXW、FCA、CPT、CIP、DAP、DPU、DDP
- **只适用于海运和内河运输（4 个）**：FAS、FOB、CFR、CIF

集装箱货物在码头堆场交给承运人，严格来说更适合用 FCA/CPT/CIP，而不是 FOB/CFR/CIF；但实务中 FOB/CIF 仍最常见。

## 逐个术语：风险在哪里转移
- **EXW 工厂交货**：卖方在自己工厂/仓库把货备好即完成交货，买方负责装车、出口清关和全程运输。卖方责任最小。出口清关由买方办，在中国实务上常导致卖方无法正常报关退税，需谨慎。
- **FCA 货交承运人**：卖方办出口清关，把货交给买方指定的承运人即转移风险。在卖方场所交货时卖方负责装货。2020 版新增：双方可约定买方指示承运人向卖方签发已装船提单，方便信用证结汇。
- **FAS 船边交货**：卖方把货放到装运港买方指定船只旁边，风险转移。
- **FOB 船上交货**：卖方在指定装运港把货装上买方指定的船，货物**装上船时**风险转移。卖方办出口清关，买方订舱付海运费和保险。
- **CFR 成本加运费**：卖方订舱付运费到目的港，但风险在装运港货物装上船时就转移给买方。
- **CIF 成本、保险加运费**：在 CFR 基础上卖方还要买海运保险，最低险别为 ICC(C) 条款，保额至少为合同金额的 110%。风险仍在装运港装船时转移。
- **CPT 运费付至**：卖方付运费到指定目的地，风险在交给第一承运人时转移。
- **CIP 运费保险付至**：在 CPT 基础上卖方买保险。2020 版把 CIP 的最低险别提高到 ICC(A) 条款（一切险级别），保额至少 110%。
- **DAP 目的地交货**：卖方承担运到指定目的地的全部风险和费用，货物在运输工具上、准备卸货时交货；进口清关和关税由买方负责。
- **DPU 目的地卸货后交货**：2020 版由 DAT 改名而来，卖方负责运到目的地**并卸货**，目的地可以是任何地点，不限于码头。是唯一要求卖方卸货的术语。
- **DDP 完税后交货**：卖方承担到目的地的全部费用和风险，包括**进口清关和进口关税、增值税**。卖方责任最大。跨境电商俗称“双清包税”。

## 关键记忆点
1. 风险转移点：F 组和 C 组都在出口国转移风险；D 组在进口国转移。
2. C 组是“费用到目的港/地，风险在起运地”，两个关键点分离，是最容易出纠纷的地方。
3. 只有 CIF 和 CIP 规定卖方必须买保险。
4. EXW 卖方责任最小，DDP 卖方责任最大。

## 新手如何选
- 刚起步、对海外物流不熟：报 FOB 或 FCA，运输由买方指定货代。
- 想掌控运输、赚取运费差价、保证船期：报 CIF/CFR。
- 跨境电商、小 B 客户不会清关：考虑 DDP，但要先算清目的国关税和增值税，并确认能合规作为进口商（Importer of Record）。

> 注：以国际商会（ICC）最新发布的 Incoterms 版本和官方解释为准。
