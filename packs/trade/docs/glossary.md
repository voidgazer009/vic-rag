# 外贸常用术语速查

- **MOQ**（Minimum Order Quantity）：最小起订量。
- **OEM**：按客户品牌和设计生产（贴牌）。**ODM**：工厂提供设计方案，客户贴牌。**OBM**：自有品牌。
- **Lead time**：交货期，从确认订单/收定金到货物可出运的时间。
- **PI**：形式发票，用于确认订单和让客户付款。
- **Inquiry / RFQ**：询盘 / 询价请求。
- **Sample**：样品；**Pre-production sample (PPS)**：产前样；**Shipping sample**：船样。
- **QC / Inspection**：质检；**AQL**：抽样检验的可接受质量水平。
- **Shipping mark**：唛头。
- **ETD / ETA**：预计开船时间 / 预计到港时间。
- **B/L copy**：提单副本，常作为尾款付款的依据。
- **Telex release**：电放，卖方同意后承运人不签发正本提单，目的港凭电放提货。
- **Chargeback**：信用卡/PayPal 拒付。
- **Sinosure**：中国出口信用保险公司（中国信保）。
