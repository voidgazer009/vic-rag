# 短视频钩子与脚本框架

## 规格常识
竖屏 **9:16**，推荐分辨率 **1080 × 1920**。字幕放在画面中部安全区，避开顶部和底部被界面遮挡的区域。多数观众静音浏览，**必须加字幕**。

## 黄金三秒：钩子（Hook）
开头 1–3 秒决定是否被划走。常见钩子类型：
- **反常识**：“外贸新人最该放弃的，就是阿里巴巴国际站。”
- **结果前置**：“这封开发信让我一周拿到 3 个询盘。”
- **提问**：“为什么你的海运费总是比别人贵 20%？”
- **数字清单**：“3 个工具，让一个人干完一个外贸团队的活。”
- **视觉冲击**：直接展示成品、工厂现场、前后对比。

## 脚本结构：Hook → Value → CTA
1. **Hook（0–3 秒）**：抓住注意力。
2. **Value（主体）**：给出干货、故事或演示，一条视频只讲一个点，每 3–5 秒有画面变化。
3. **CTA（结尾）**：一个明确动作，如“关注看下一集”“评论区回复‘模板’领取”。

## 其他常用框架
- **PAS**：问题（Problem）→ 放大痛点（Agitate）→ 解决方案（Solution）。
- **故事型**：冲突 → 转折 → 结果 → 启发。
- **教程型**：结果展示 → 步骤 1/2/3 → 总结。

## 时长建议
15–45 秒的短视频最容易完播；教程类可以到 60–90 秒，但要保证节奏紧凑。YouTube Shorts 和 Instagram Reels 现在都支持最长 3 分钟的视频，但更长不代表更好。
