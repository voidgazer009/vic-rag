# 海外主流社交平台定位

## 平台速览
- **LinkedIn（领英）**：职场与 B2B 平台，适合外贸、物流、企业服务、个人专业品牌。决策人集中，图文帖、文档轮播（PDF carousel）、短视频都有效。
- **YouTube（油管）**：长视频搜索引擎，内容生命周期长，适合教程、测评、工厂探访。**Shorts** 竖屏短视频可带动订阅。
- **TikTok**：短视频推荐算法驱动，冷启动快，适合消费品、生活方式、娱乐化内容；TikTok Shop 可直接带货（开通国家有限）。
- **Instagram**：视觉化平台，Reels 短视频、轮播图、快拍（Stories）；适合消费品牌、设计、时尚、美食。
- **Facebook（脸书）**：用户基数大，年龄偏大；群组（Groups）和公共主页、广告投放能力强，适合本地商家和 B2C 广告。
- **X（原 Twitter）**：实时信息和观点交流，科技、AI、投资圈活跃，适合 Build in Public 和思想领导力。
- **Pinterest**：灵感搜索平台，适合家居、手工、婚礼、电商导流，内容生命周期长。

## 按目标选平台
| 目标 | 首选平台 |
|---|---|
| B2B 外贸/物流获客 | LinkedIn + YouTube |
| 消费品带货 | TikTok + Instagram |
| AI/科技个人品牌 | X + LinkedIn + YouTube |
| 长期搜索流量 | YouTube + Pinterest + 博客 |

## 起步建议
一个人精力有限：选 **1 个主平台** 深耕，再用一稿多发覆盖 2–3 个次平台。所有平台统一头像、名字和简介，简介写清“你帮谁解决什么问题”，并放一个链接入口。
