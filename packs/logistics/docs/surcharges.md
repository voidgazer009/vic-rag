# 海运附加费与杂费清单

货代报价常写成“海运费 + 附加费 + 起运港杂费 + 目的港杂费”。比价时务必让对方给出 **all-in** 总价，避免低价引流、到港加价。

## 海运费附加费
- **BAF 燃油附加费**（Bunker Adjustment Factor）：随油价调整。
- **LSS 低硫附加费**：IMO 2020 限硫令后船司普遍收取。
- **CAF 货币贬值附加费**：汇率波动时收取。
- **PSS 旺季附加费**：旺季舱位紧张时收取。
- **GRI 综合费率上涨**：船司统一涨价通知。
- **EBS / EFS 等紧急燃油附加费**：特殊时期临时收取。

## 起运港费用（中国出口端常见）
- **THC 码头操作费**（Terminal Handling Charge）
- **DOC 文件费 / 提单费**
- **封条费（Seal）**
- **报关费、拖车费、港杂费**
- **AMS / ENS / ACI 申报费**：按目的国要求预申报舱单产生的费用。
- **电放费**：选择电放时收取。

## 目的港费用
- 目的港 THC、换单费（D/O fee）、清关费、关税和进口增值税、内陆派送费。
- **滞箱费 Detention / 滞港费（堆存费）Demurrage**：超过免柜期后按天累进收费，是目的港最容易失控的成本。

## 控制成本的做法
1. 要求 all-in 报价并写明有效期和包含项目。
2. 提前和货代确认目的港免柜期，必要时申请延长。
3. 旺季（通常是欧美圣诞备货季，以及春节前）提前 2–4 周订舱。
4. 多比较 2–3 家货代，重点看服务和异常处理能力，不只看价格。

> 注：附加费名目和金额会变化，以船司和货代最新报价为准。
